## 1. 通用语言定义

| 术语 | 定义 |
| :--- | :--- |
| **物品** | 用户拥有的一件有形实物，是产品管理的原子单位 |
| **固定资产** | 用户主动标记为需进行折旧管理的耐用物品 |
| **空间** | 物品的物理存放位置，如“书房 > 书桌 > 第一层抽屉” |
| **陪伴天数** | 从购买日到今天的天数 |
| **日均成本** | 购买价格 ÷ 陪伴天数 |
| **闲置** | 连续未打卡超过指定天数的状态 |
| **折旧** | 固定资产价值随时间递减的财务模拟 |
| **净值** | 固定资产扣除累计折旧后的剩余账面价值 |
| **残值** | 折旧完成后的恒定净值 |
| **维持期** | 折旧完成后的状态，净值恒定为残值，不再产生折旧 |
| **维护成本** | 维修、保养等追加支出 |
| **总投入** | 购买价格 + 累计维护支出 |
| **物超所值** | 当前净值 ≥ 总投入或折旧完成后继续使用产生的正向心理价值 |
| **愿望** | 用户想买但尚未购买的物品 |
| **冷却期** | 愿望创建后到可做购买决定之间的强制等待时间 |

## 2. 产品信息架构

```

│   ├── 物品列表      （浏览、搜索、筛选、批量操作）

```

## 3. 核心页面设计

### 3.1 仪表盘

**页面定位**：启动后的默认首页，提供资产快照及净值视角。

| 区域 | 内容 | 交互 |
| :--- | :--- | :--- |
| **概览卡片** | 物品总数、资产总值（原值）、资产总净值、本月折旧总额 | 点击卡片跳转到对应列表或报表；卡片右上角可切换“原值/净值”视角 |
| **品类占比图** | 可选择按原值或净值展示品类占比 | 悬浮显示品类、金额、百分比；点击图例筛选 |
| **购买趋势图** | 近12个月购买金额柱状图 | 悬浮显示当月具体金额 |
| **Top5 日均成本** | 日均成本最高的5件物品，若有固定资产则同时展示其日均折旧 | 点击物品名跳转详情 |

**空状态**：首次使用时，显示欢迎插画和“添加第一件物品”引导按钮。

**验收标准**：
- [ ] 仪表盘各项数据在物品变更后即时刷新
- [ ] 原值/净值切换时，概览卡片和品类占比图同步切换
- [ ] 退役物品不参与仪表盘所有计算
- [ ] 无物品时正确显示空状态引导

---

### 3.2 物品库

**页面定位**：物品管理的核心工作区。

#### 3.2.1 物品列表

*   **视图切换**：网格视图和列表视图，默认网格。
*   **列表信息项**：缩略图、名称、品类标签、购买日期、日均成本、固定资产标识（如有）、净值率（固定资产）。
*   **排序方式**：按添加时间、购买日期、日均成本、陪伴天数、净值高低。
*   **搜索与筛选**：按名称、品类、备注搜索；按品类、空间、购买时间范围、是否固定资产筛选。
*   **批量操作**：多选后批量删除、批量修改空间。
*   **添加入口**：界面右上角固定“+ 添加物品”按钮。

**验收标准**：
- [ ] 两种视图切换流畅，无数据错乱
- [ ] 搜索在输入停止300ms后返回结果
- [ ] 筛选条件可组合使用，重置清空所有条件
- [ ] 批量操作有明确的选中状态视觉反馈
- [ ] 空列表时显示引导文案

#### 3.2.2 物品详情

| 信息区 | 内容 |
| :--- | :--- |
| **图片区** | 物品图片轮播，支持放大查看 |
| **基本信息** | 名称、品类、购买日期、价格、保修到期日、空间位置、固定资产开关状态及参数 |
| **成本与净值卡片** | 陪伴天数、日均成本、累计打卡次数、次均成本；固定资产则额外显示净值、累计折旧、净值率；总投入及差值；维持期标识及激励文案 |
| **使用打卡** | 日历热力图 + “今日打卡”按钮 |
| **时间线** | 事件按时间倒序，维护事件以扳手图标区分 |
| **评分** | 1-5星评分 |

**操作按钮**：编辑、标记固定资产/取消、标记退役/恢复、删除（需确认）。

**维持期特殊展示**：
- 净值卡片显示“维持期”标签。
- 文案：“这件物品已完成折旧，每次使用都是额外价值。”
- 净值恒定为残值。

**验收标准**：
- [ ] 打开详情时净值等数据实时计算
- [ ] 固定资产开关在编辑模式下正常展开/收起相关字段
- [ ] 退役和恢复操作后状态即时同步到列表
- [ ] 打卡操作当日仅可执行一次
- [ ] 维护事件金额录入后总投入即时更新

#### 3.2.3 添加 / 编辑物品

*   **展现形式**：弹窗（默认）或独立页面（V2.0 可选）。
*   **必填字段**：物品名称。
*   **选填字段**：图片、品类、购买日期、价格、保修到期日、空间、备注。
*   **固定资产开关**：默认关闭。开启后展开使用年限、残值、折旧方法。

**验收标准**：
- [ ] 必填项为空时保存按钮禁用或给出明确提示
- [ ] 品类输入支持模糊匹配已有项和即时新建
- [ ] 图片拖拽上传后即时显示缩略图
- [ ] 固定资产开关开启后字段展开且使用年限、残值为必填
- [ ] 编辑模式下预填所有已有数据

### 3.3 洞察

**页面定位**：基于数据生成反思视角，突出闲置期间的折旧损失。

#### 3.3.1 闲置清单

*   **筛选条件**：闲置天数阈值（默认60天，可调），新增“仅看固定资产”。
*   **列表内容**：物品名称、品类、购买价格、闲置天数、沉默成本、闲置期间折旧、总投入。
*   **汇总统计**：闲置总数、沉默成本总和、折旧总和。
*   **导出**：CSV。

**验收标准**：
- [ ] 修改阈值后列表即时刷新
- [ ] 废旧和退役物品不出现在清单中
- [ ] CSV 导出列完整且数据正确

#### 3.3.2 后悔榜

*   **计算因子**：评分、闲置天数、净值折损速度。
*   **展示**：卡片列表，含图片、名称、评分、闲置天数、净值率。

**验收标准**：
- [ ] 未评分物品不出现在榜单
- [ ] 榜单按后悔指数降序排列
- [ ] 退役物品不出现在榜单

---

### 3.4 决策

#### 3.4.1 愿望清单

*   **列表内容**：愿望名称、期望价格、添加日期、剩余冷却天数。
*   **状态**：冷却中（倒计时）、待评估（确认购买/放弃）。
*   **克制记录**：放弃后记录。

**验收标准**：
- [ ] 冷却期未到时操作区不可用
- [ ] 冷却到期后自动变为待评估
- [ ] 放弃操作不可撤销

#### 3.4.2 不买计算器

*   **输入**：商品名称和价格。
*   **匹配**：闲置物品中总价相近（±10%）的组合，优先件数最少。
*   **展示**：对比卡片，列出闲置物品及其净值、折旧。

**验收标准**：
- [ ] 匹配结果为非退役闲置物品
- [ ] 多组合时展示最精简的一个
- [ ] 无匹配时显示正向鼓励文案

## 4. 用户操作流程

### 4.1 将物品设为固定资产并查看折旧
```
添加物品 → 开启“固定资产”开关 → 输入使用年限、残值、选折旧法 → 保存
→ 进入物品详情 → 成本卡片显示净值、累计折旧
→ 随时间推移，净值逐日减少
→ 到达使用年限，自动切换“维持期”，显示鼓励文案
```

### 4.2 记录维护成本并查看总投入
```
进入物品详情 → 时间线 → 添加事件 → 选择“维护/维修” → 输入金额
→ 保存后，成本卡片“总投入”更新
→ 若总投入已超过净值，差值以红色提示
```

### 4.3 利用折旧进行消费克制
```
看中商品 → 打开不买计算器 → 输入名称价格
→ 查看匹配到的闲置固定资产及其累计折旧、当前净值
→ 意识到“买后不用”的真实代价 → 加入愿望清单冷却
```

## 5. 设计规则与约束

### 5.1 交互规则
*   **本地优先**：所有操作默认无需网络。
*   **即时反馈**：增删改即时生效，折旧数据每次打开详情时实时计算。
*   **二次确认**：删除物品、清空数据需确认；退役固定资产时提醒“将停止折旧”。
*   **空状态引导**：无物品、无闲置等场景提供正向文案。

### 5.2 数据展示规则

| 规则 | 说明 |
| :--- | :--- |
| 退役物品隔离 | 退役物品不参与闲置清单、后悔榜、仪表盘计算，但保留历史数据 |
| 固定资产折旧停止 | 退役或进入维持期后，折旧不再继续；退役则净值定格在退役时的净值 |
| 净值计算基准 | 以“天”为最小单位进行折旧，打开详情时实时显示当日净值 |
| 货币与日期格式化 | 根据语言环境自动适配 |
| 用户数据不翻译 | 物品名、备注、空间名保持用户输入原样 |

### 5.3 国际化规则
*   所有界面文案独立语言文件管理。
*   固定资产相关术语提供三语翻译。
*   品类默认年限推荐等预设数据本地化。

## 6. 异常状态与边界处理

### 6.1 输入边界

| 字段 | 约束 | 违规行为及处理 |
| :--- | :--- | :--- |
| 物品名称 | 1-200字符，不可纯空格 | 超长自动截断并提示；纯空格阻止保存并给出提示 |
| 购买价格 | 0 - 99,999,999.99，正数 | 非法字符（负号、字母）阻止输入；0 视为未填写，保持空值 |
| 预估残值 | 0 ≤ 残值 < 购买价格 | 残值 ≥ 购买价格时提示“残值应小于购买价格” |
| 使用年限 | 1 - 100 整数 | 输入非整数或越界时阻止保存并提示 |
| 维护金额 | 0 - 99,999,999.99 | 非法字符阻止输入；可为空 |
| 愿望名称 | 1-200字符 | 同物品名称规则 |
| 期望价格 | 同购买价格 | 同购买价格规则 |
| 冷却天数 | 1-365 整数 | 默认7，越界时提示并恢复默认值 |
| 评分 | 1-5 整数 | — |
| 备注 | 0-500字符 | 超长自动截断 |

### 6.2 数据冲突与异常

| 异常场景 | 期望行为 |
| :--- | :--- |
| **品类名与系统预设重名** | 用户自定义品类以独立标识存储，不与系统预设混淆，列表中可能出现两个显示名相同的品类但 key 不同 |
| **导入备份中的物品ID与现有ID冲突** | V1.0 恢复备份为全量替换，需二次确认“将覆盖当前所有数据” |
| **图片文件被外部删除** | 物品详情中该图片位置显示占位图，用户可手动删除或补充 |
| **修改购买价格后** | 所有成本卡片数据（原值、折旧、总投入）即时重算 |
| **同时使用两个实例（V1.0无同步不支持，但用户可能手动复制数据库）** | V1.0 不处理，V2.0 需设计冲突策略 |
| **数据库被外部损坏** | 启动时检测数据库完整性，异常时提示用户恢复备份或新建数据库 |
| **磁盘空间不足无法保存** | 保存操作失败时给予明确提示“磁盘空间不足”，不静默丢失数据 |

### 6.3 操作边界

| 场景 | 期望行为 |
| :--- | :--- |
| **退役物品后再编辑** | 可正常编辑除财务关键字段（购买价格、固定资产标记）外的信息，但退役状态不可影响历史报表数据 |
| **删除有维护记录或打卡记录的物品** | 二次确认时明确告知该物品关联的所有记录将被永久删除 |
| **打卡日跨时区** | 打卡日期以用户本地日期为准，非 UTC |
| **折旧跨越闰年/2月** | 按实际公历日期计算，每日折旧额 = 年折旧额 ÷ 当年总天数 |
| **在维持期修改使用年限或残值** | 维持期自动结束，物品重新进入折旧期，按新参数重新计算折旧（历史折旧不变，从修改日重新计算） |
| **固定资产取消标记** | 所有折旧记录保留但不再展示，物品恢复为普通物品，成本卡片隐藏净值等字段 |

### 6.4 极限情况

| 极限场景 | 期望行为 |
| :--- | :--- |
| **物品数量 0** | 仪表盘、列表、闲置清单、后悔榜均显示各自空状态 |
| **连续365天未打卡** | 闲置天数正常累计，折旧（若有）正常计入 |
| **购买日期晚于今天** | 允许录入（预购物品），但陪伴天数为负数时不展示，显示“未到手” |
| **所有物品都退役** | 仪表盘显示原值/净值总和，但闲置和后悔榜均为空 |
| **快速连续点击打卡** | 按钮在第一次有效打卡后立即置灰，后续点击无响应，不重复记录 |
| **窗口宽度极端拉窄** | 当小于 900px 时，侧栏自动折叠为汉堡菜单；小于 700px 时，部分卡片堆叠显示 |

## 7. V2.0 功能展望
