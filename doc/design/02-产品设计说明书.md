## 1. 通用语言定义

为确保团队对核心概念有统一理解，先定义产品中反复出现的术语。

| 术语 | 定义 |
| :--- | :--- |
| **物品** | 用户拥有的一件有形实物，是产品管理的原子单位 |
| **固定资产** | 用户主动标记为需进行折旧管理的耐用物品，如手机、家电、汽车 |
| **空间** | 物品的物理存放位置，如“书房 > 书桌 > 第一层抽屉” |
| **陪伴天数** | 从购买日到今天的天数 |
| **日均成本** | 购买价格 ÷ 陪伴天数 |
| **闲置** | 连续未打卡超过指定天数的状态 |
| **折旧** | 固定资产价值随时间递减的财务模拟 |
| **净值** | 固定资产扣除累计折旧后的剩余账面价值 |
| **残值** | 折旧完成后的恒定净值 |
| **维持期** | 折旧完成后的状态，净值恒定为残值，不再产生折旧 |
| **维护成本** | 维修、保养等追加支出 |
| **总投入** | 购买价格 + 累计维护支出 |
| **物超所值** | 当前净值 ≥ 总投入或折旧完成后继续使用产生的正向心理价值 |
| **愿望** | 用户想买但尚未购买的物品 |
| **冷却期** | 愿望创建后到可做购买决定之间的强制等待时间 |

## 3. 核心页面设计

### 3.1 仪表盘

**页面定位**：启动后的默认首页，提供资产快照及净值视角。

| 区域 | 内容 | 交互 |
| :--- | :--- | :--- |
| **概览卡片** | 物品总数、资产总值（原值）、**资产总净值**、本月折旧总额 | 点击卡片跳转到对应列表或报表；卡片右上角可切换“原值/净值”视角 |
| **品类占比图** | 可选择按原值或净值展示品类占比 | 悬浮显示品类、金额、百分比；点击图例筛选 |
| **购买趋势图** | 近12个月购买金额柱状图 | 悬浮显示当月具体金额 |
| **Top5 日均成本** | 日均成本最高的5件物品，若有固定资产则同时展示其日均折旧 | 点击物品名跳转详情 |

**空状态**：首次使用时，显示欢迎插画和“添加第一件物品”引导按钮。

---

### 3.2 物品库

**页面定位**：物品管理的核心工作区。

#### 3.2.1 物品列表

*   **视图切换**：网格视图（展示缩略图）和列表视图（展示详细信息），默认网格。
*   **列表信息项**：缩略图、名称、品类标签、购买日期、日均成本、**固定资产标识**（如有，展示小图标）、**净值/原值百分比**（若为固定资产则在名称旁显示净值率）。
*   **排序方式**：按添加时间、购买日期、日均成本、陪伴天数、**净值高低**排序。
*   **搜索与筛选**：支持按名称、品类、备注搜索；按品类、空间、购买时间范围筛选；**新增“是否固定资产”筛选**。
*   **批量操作**：多选后批量删除、批量修改空间。
*   **添加入口**：界面右上角固定“+ 添加物品”按钮。

#### 3.2.2 物品详情

| 信息区 | 内容 |
| :--- | :--- |
| **图片区** | 物品图片轮播，支持放大查看 |
| **基本信息** | 名称、品类、购买日期、价格、保修到期日、空间位置<br>**新增“固定资产”开关状态**，若开启则显示：使用年限、折旧方法、残值 |
| **成本与净值卡片** | - 陪伴天数、日均成本<br>- 累计打卡次数、次均成本<br>- **若为固定资产**：当前账面净值、累计折旧、净值率、折旧曲线缩略图<br>- **总投入**（购买价格 + 累计维护支出）<br>- **净值与总投入的差值**（负值红色提示，正值绿色鼓励）<br>- **维持期标识**：折旧完成时显示“维持期”标签及正向文案 |
| **使用打卡** | 日历热力图 + “今日打卡”按钮 |
| **时间线** | 按时间倒序展示事件，**维护事件以扳手图标区分**，事件可附带金额 |
| **评分** | 1-5星评分，用于后悔榜计算 |

**操作按钮**：编辑物品、标记固定资产/取消、标记退役/恢复、删除（需确认）。

**维持期特殊展示**：
- 净值卡片区域显示“维持期”标签。
- 文案：“这件物品已在本月完成折旧，此后每次使用，都是它为你创造的额外价值。”
- 净值恒定为残值，不再更新折旧数据。

#### 3.2.3 添加 / 编辑物品

*   **展现形式**：弹窗（快速录入）或独立页面（V2.0 提供切换）。
*   **必填字段**：物品名称。
*   **选填字段**：图片、品类、购买日期、价格、保修到期日、空间位置、备注。
*   **新增“固定资产”开关**：
    *   默认关闭。
    *   开启后展开：使用年限（输入或按品类推荐）、预估残值（金额或百分比）、折旧方法（直线/加速）。
*   **保存后**：弹窗关闭，列表刷新。

### 3.3 洞察

**页面定位**：基于数据生成反思视角，突出闲置期间的折旧损失。

#### 3.3.1 闲置清单

*   **筛选条件**：闲置天数阈值（默认60天，可调），**新增“仅看固定资产”选项**。
*   **列表内容**：物品名称、品类、购买价格、闲置天数、**沉默成本（原值）**、**闲置期间折旧额**、**总投入**。
*   **汇总统计**：闲置物品总数、沉默成本总和、**闲置期间折旧总和**。
*   **排序**：默认按沉默成本或折旧额从高到低。
*   **导出**：支持导出为 CSV，包含净值与折旧列。
*   **物品点击**：跳转到物品详情。

#### 3.3.2 后悔榜

*   **计算因子**：用户评分（1-5星）、闲置天数、**净值折损速度**（固定资产专属，净值率越低后悔度越高）。
*   **展示**：卡片列表，显示物品图片、名称、评分、闲置天数、**净值率或折旧情况**。
*   **筛选**：时间范围（全部/一年/半年）。

### 3.4 决策

**页面定位**：购物冲动管理，通过折旧对比提升克制力。

#### 3.4.1 愿望清单

（保持原有设计不变：愿望名称、期望价格、冷却天数、倒计时、状态流转、克制记录）

#### 3.4.2 不买计算器

*   **输入**：想买物品的名称和价格。
*   **匹配逻辑**：从闲置物品（含固定资产）中找出总价与输入价格相近（±10%）的组合。
*   **结果展示**：
    *   左侧“你想买的”：名称、价格。
    *   右侧“你已有的闲置”：匹配到的闲置物品列表，每件显示：
        *   名称、购买价格、**累计折旧**、**当前净值**。
    *   底部展示匹配物品的**折旧损失总和**与**沉默成本总和**。
*   **引导操作**：底部“加入愿望清单”按钮。
*   **无匹配**：正向鼓励，“你暂无闲置物品，继续保持～”。

## 4. 用户操作流程（新增折旧相关）

### 4.1 将物品设为固定资产并查看折旧
```
添加物品 → 开启“固定资产”开关 → 输入使用年限、残值、选折旧法 → 保存
→ 进入物品详情 → 成本卡片显示净值、累计折旧
→ 随着时间推移，净值逐月减少
→ 到达使用年限后，自动切换“维持期”，显示鼓励文案
```

### 4.2 记录维护成本并查看总投入
```
进入物品详情 → 时间线 → 添加事件 → 选择“维护/维修” → 输入金额
→ 保存后，成本卡片“总投入”更新
→ 若总投入已超过净值，差值以红色提示
```

### 4.3 利用折旧进行消费克制
```
看中商品 → 打开不买计算器 → 输入名称价格 → 查看匹配到的闲置固定资产
→ 看到它们的累计折旧和当前净值 → 意识到“买后不用”的真实代价
→ 加入愿望清单冷却
```

## 5. 设计规则与约束

### 5.1 交互规则
*   **本地优先**：所有操作默认无需网络。
*   **即时反馈**：增删改即时生效，折旧数据每次打开详情时实时计算。
*   **二次确认**：删除物品、清空数据需确认；退役固定资产时可提醒“将停止折旧”。
*   **空状态引导**：无物品、无闲置等场景提供正向文案。

### 5.2 数据展示规则
| 规则 | 说明 |
| :--- | :--- |
| 退役物品隔离 | 退役物品不参与闲置清单、后悔榜、仪表盘计算，但保留历史数据 |
| 固定资产折旧停止 | 退役或进入维持期后，折旧不再继续；退役则净值定格在退役时的净值 |
| 净值计算基准 | 系统以“天”为最小单位进行折旧计算，打开详情时实时显示当日净值 |
| 货币与日期格式化 | 根据语言环境自动适配 |
| 用户数据不翻译 | 物品名、备注、空间名保持用户输入原样 |

### 5.3 国际化规则
*   所有界面文案独立语言文件管理。
*   固定资产相关术语（折旧、净值、残值等）需提供三语翻译。
*   品类默认年限推荐等预设数据也需本地化。
