## 1. 表结构总览

| 表名 | 存储内容 | 引擎 | 字符集 |
| :--- | :--- | :--- | :--- |
| categories | 物品品类 | SQLite | UTF-8 |
| spaces | 物品存放空间 | SQLite | UTF-8 |
| items | 物品主数据 | SQLite | UTF-8 |
| item_images | 物品图片引用 | SQLite | UTF-8 |
| checkins | 使用打卡记录 | SQLite | UTF-8 |
| events | 物品生命周期事件 | SQLite | UTF-8 |
| wishes | 愿望清单 | SQLite | UTF-8 |
| restraint_records | 克制记录 | SQLite | UTF-8 |

## 2. 详细字段定义

### 2.1 categories

| 字段名 | 类型 | 长度/范围 | 必填 | 默认值 | 说明 |
| :--- | :--- | :--- | :--- | :--- | :--- |
| id | TEXT | UUID v4 或语义化标识 | 是 | — | 主键；预设品类使用 cat-xxx 格式，用户自定义品类使用 UUID v4 |
| key | TEXT | 1..100 | 是 | — | 唯一标识；预设品类使用英文语义标识（如 'electronics'），用户自定义品类使用 UUID v4 自动生成 |
| name | TEXT | 1..200 | 否 | NULL | 用户自定义品类的显示名；NULL 表示预设品类，由 i18n key 映射显示名 |
| parent_id | TEXT | UUID | 否 | NULL | 父品类外键，引用 categories.id |

**索引**：
- `UNIQUE INDEX idx_categories_key ON categories(key)`

**外键**：
- `parent_id` → `categories(id)`，ON DELETE SET NULL

### 2.2 spaces

| 字段名 | 类型 | 长度/范围 | 必填 | 默认值 | 说明 |
| :--- | :--- | :--- | :--- | :--- | :--- |
| id | TEXT | UUID v4 | 是 | — | 主键 |
| name | TEXT | 1..200 | 是 | — | 用户自由输入，不翻译 |
| parent_id | TEXT | UUID | 否 | NULL | 父空间外键，引用 spaces.id |

**索引**：无额外索引，主键即索引

**外键**：
- `parent_id` → `spaces(id)`，ON DELETE SET NULL

### 2.3 items

| 字段名 | 类型 | 长度/范围 | 必填 | 默认值 | 说明 |
| :--- | :--- | :--- | :--- | :--- | :--- |
| id | TEXT | UUID v4 | 是 | — | 主键 |
| name | TEXT | 1..200 | 是 | — | 物品名称，不可纯空格 |
| category_id | TEXT | UUID | 否 | NULL | 外键 → categories.id |
| space_id | TEXT | UUID | 否 | NULL | 外键 → spaces.id |
| purchase_date | DATE | 不早于1900-01-01 | 否 | NULL | 购买日期；允许未来日期（预购物品），届时显示"未到手" |
| purchase_price | REAL | 0 .. 99999999.99 | 否 | NULL | 购买价格 |
| warranty_expiry | DATE | — | 否 | NULL | 保修到期日 |
| is_fixed_asset | INTEGER | 0/1 | 否 | 0 | 是否固定资产 |
| useful_life_years | INTEGER | 1 .. 100 | 否 | NULL | 使用年限（固定资产必填） |
| residual_value | REAL | 0 ≤ 值 < purchase_price | 否 | NULL | 预估残值（固定资产必填） |
| depreciation_method | TEXT | 'LINEAR' 或 'ACCELERATED' | 否 | NULL | 折旧方法（固定资产必填） |
| status | TEXT | 'ACTIVE' 或 'RETIRED' | 否 | 'ACTIVE' | 物品状态 |
| rating | INTEGER | 1 .. 5 | 否 | NULL | 用户满意度评分 |
| notes | TEXT | 0 .. 500 | 否 | NULL | 备注 |
| estimated_value | REAL | 0 .. 99999999.99 | 否 | NULL | 当前估值（普通物品可选填写） |
| created_at | DATETIME | ISO8601 | 否 | 插入时当前时间 | — |
| updated_at | DATETIME | ISO8601 | 否 | 插入时当前时间，更新时自动刷新 | — |

**索引**：
- `INDEX idx_items_category ON items(category_id)`
- `INDEX idx_items_space ON items(space_id)`
- `INDEX idx_items_status ON items(status)`
- `INDEX idx_items_name ON items(name)`

**外键**：
- `category_id` → `categories(id)`，ON DELETE SET NULL
- `space_id` → `spaces(id)`，ON DELETE SET NULL

### 2.4 item_images

| 字段名 | 类型 | 长度/范围 | 必填 | 默认值 | 说明 |
| :--- | :--- | :--- | :--- | :--- | :--- |
| id | TEXT | UUID v4 | 是 | — | 主键 |
| item_id | TEXT | UUID v4 | 是 | — | 外键 → items.id，级联删除 |
| image_path | TEXT | 相对路径 | 是 | — | 相对应用 images/ 的路径，以 UUID 命名 |
| sort_order | INTEGER | ≥0 | 否 | 0 | 排序 |

**索引**：
- `INDEX idx_item_images_item ON item_images(item_id)`

**外键**：
- `item_id` → `items(id)`，ON DELETE CASCADE

### 2.5 checkins

| 字段名 | 类型 | 长度/范围 | 必填 | 默认值 | 说明 |
| :--- | :--- | :--- | :--- | :--- | :--- |
| id | TEXT | UUID v4 | 是 | — | 主键 |
| item_id | TEXT | UUID v4 | 是 | — | 外键 → items.id，级联删除 |
| check_date | DATE | 不晚于当前日期 | 是 | — | 打卡日期 |
| created_at | DATETIME | ISO8601 | 否 | 当前时间 | — |

**唯一约束**：
- `UNIQUE(item_id, check_date)` — 同物品同日只可打卡一次

**外键**：
- `item_id` → `items(id)`，ON DELETE CASCADE

### 2.6 events

| 字段名 | 类型 | 长度/范围 | 必填 | 默认值 | 说明 |
| :--- | :--- | :--- | :--- | :--- | :--- |
| id | TEXT | UUID v4 | 是 | — | 主键 |
| item_id | TEXT | UUID v4 | 是 | — | 外键 → items.id，级联删除 |
| event_type | TEXT | 枚举值见下 | 是 | — | 事件类型 |
| description | TEXT | 0 .. 500 | 否 | NULL | 事件描述 |
| amount | REAL | 0 .. 99999999.99 | 否 | NULL | 金额（维护事件可选） |
| occurred_at | DATE | — | 是 | — | 事件发生日期 |
| created_at | DATETIME | ISO8601 | 否 | 当前时间 | — |

**event_type 枚举**：
- `PURCHASED`：购入（系统自动创建）
- `MAINTENANCE`：维护/维修
- `LENT`：借出
- `RETURNED`：归还
- `RETIRED`：退役（系统自动创建）
- `CUSTOM`：自定义

**索引**：
- `INDEX idx_events_item ON events(item_id, occurred_at)`

**外键**：
- `item_id` → `items(id)`，ON DELETE CASCADE

### 2.7 wishes

| 字段名 | 类型 | 长度/范围 | 必填 | 默认值 | 说明 |
| :--- | :--- | :--- | :--- | :--- | :--- |
| id | TEXT | UUID v4 | 是 | — | 主键 |
| name | TEXT | 1 .. 200 | 是 | — | 愿望物品名 |
| expected_price | REAL | 0 .. 99999999.99 | 否 | NULL | 期望价格 |
| cooling_days | INTEGER | 1 .. 365 | 否 | 7 | 冷却天数 |
| status | TEXT | 枚举值见下 | 否 | 'COOLING' | 状态 |
| created_at | DATE | 默认当前日期 | 否 | date('now') | 创建日期 |
| decided_at | DATE | — | 否 | NULL | 做出决策的日期 |

**status 枚举**：
- `COOLING`：冷却中
- `REVIEWABLE`：待评估
- `PURCHASED`：已购买
- `ABANDONED`：已放弃

**索引**：
- `INDEX idx_wishes_status ON wishes(status)`

### 2.8 restraint_records

| 字段名 | 类型 | 长度/范围 | 必填 | 默认值 | 说明 |
| :--- | :--- | :--- | :--- | :--- | :--- |
| id | TEXT | UUID v4 | 是 | — | 主键 |
| wish_id | TEXT | UUID v4 | 是 | — | 外键 → wishes.id，级联删除 |
| decision | TEXT | 'PURCHASED' 或 'ABANDONED' | 是 | — | 决策结果 |
| decided_at | DATE | — | 是 | — | 决策日期 |

**索引**：
- `INDEX idx_restraint_wish ON restraint_records(wish_id)`

**外键**：
- `wish_id` → `wishes(id)`，ON DELETE CASCADE

## 3. 外键与级联规则汇总

| 子表 | 外键列 | 父表 | 删除规则 | 说明 |
| :--- | :--- | :--- | :--- | :--- |
| items | category_id | categories | SET NULL | 删除品类时物品品类置空 |
| items | space_id | spaces | SET NULL | 删除空间时物品空间置空 |
| categories | parent_id | categories | SET NULL | 删除父品类时子品类置顶 |
| spaces | parent_id | spaces | SET NULL | 删除父空间时子空间置顶 |
| item_images | item_id | items | CASCADE | 删除物品时级联删除图片记录和文件 |
| checkins | item_id | items | CASCADE | 删除物品时级联删除打卡记录 |
| events | item_id | items | CASCADE | 删除物品时级联删除时间线 |
| restraint_records | wish_id | wishes | CASCADE | 删除愿望时删除关联克制记录 |

## 4. 数据校验规则汇总

| 字段 | 校验规则 | 实现位置 |
| :--- | :--- | :--- |
| name (items) | 长度1-200，不可纯空格 | 前端 + 后端 |
| purchase_price | 0..99999999.99，NULL 表示未填写，0 为合法值 | 前端 + 后端 |
| estimated_value | 0..99999999.99，NULL 表示未填写 | 前端 + 后端 |
| residual_value | 0 ≤ 且 < purchase_price | 前端 + 后端 |
| useful_life_years | 1..100 整数 | 前端 + 后端 |
| depreciation_method | 仅 LINEAR / ACCELERATED | 后端 |
| status (items) | 仅 ACTIVE / RETIRED | 后端 |
| rating | 1..5 | 前端 + 后端 |
| notes (items) | 前端截断至500字符并提示已截断；后端拒绝超500字符 | 前端 + 后端 |
| event_type | 预定义枚举 | 后端 |
| amount (events) | 0..99999999.99，可为空 | 前端 + 后端 |
| check_date | 不晚于当前日期 | 后端 |
| name (wishes) | 长度1-200，不可纯空格 | 前端 + 后端 |
| expected_price (wishes) | 同 purchase_price | 前端 + 后端 |
| wish cooling_days | 1..365，前端越界时自动恢复默认值7并提示有效范围 | 前端 + 后端 |
| wish status | 仅 COOLING / REVIEWABLE / PURCHASED / ABANDONED | 后端 |
| wish decision | 仅 PURCHASED / ABANDONED | 后端 |
| 退役物品折旧 | 退役固定资产净值定格在退役事件日期，不再继续折旧 | 后端 |

**特殊说明**：
- 愿望 PURCHASED 状态表示用户已决定购买，但不会自动创建物品记录。用户需手动在物品库中添加对应物品。
- `get_wishes` 查询时自动将已过冷却期的 COOLING 愿望更新为 REVIEWABLE，确保 `decide_wish` 可正常处理。

## 6. 版本兼容性

- **向前兼容**：V1.0 备份文件可在后续版本恢复，后续版本新增字段时提供默认值。
- **数据库迁移**：通过 `_migrations` 表管理版本，按顺序执行 SQL 脚本，确保升级平滑。
- **字段新增**：新增字段必须有 DEFAULT 值或允许 NULL，确保旧版本数据可升级。
