### 2.3 状态管理（Zustand Stores）

#### 2.3.1 `useItemStore`

```typescript
interface ItemState {
  items: Item[];                // 当前视图的物品列表（可能分页）
  totalCount: number;           // 符合条件的物品总数
  currentItem: Item | null;     // 详情页当前物品
  filters: {
    search: string;
    categoryId: string | null;
    spaceId: string | null;
    dateRange: [Date, Date] | null;
    isFixedAsset: boolean | null;
  };
  sort: { field: string; order: 'asc' | 'desc' };
  viewMode: 'grid' | 'list';
  page: number;
  pageSize: number;

  // Actions
  fetchItems: () => Promise<void>;
  fetchItemById: (id: string) => Promise<void>;
  addItem: (payload: CreateItemPayload) => Promise<void>;
  updateItem: (id: string, payload: UpdateItemPayload) => Promise<void>;
  deleteItem: (id: string) => Promise<void>;
  setFilter: (key: string, value: any) => void;
  setSort: (field: string) => void;
  setViewMode: (mode: 'grid' | 'list') => void;
  setPage: (page: number) => void;
}
```

**实现要点**：

- `fetchItems` 调用 `invoke('get_items', { filters, sort, page, pageSize })`，返回分页数据
- 物品保存后刷新当前页；删除后若当前页变空则回退一页
- 排序字段映射为后端可用字段名：`dailyCost` → `purchase_price / accompany_days`（后端处理）
- 筛选条件变化时重置 page 为 1，避免空白页
- `viewMode` 存储在 `localStorage`，下次打开保持

**统一错误处理**：在调用处使用 `try/catch`，解析 Tauri 错误并展示用户友好提示：

```typescript
// utils/handleError.ts
export function handleError(error: any): string {
  if (typeof error === 'string') {
    // 尝试匹配错误码
    const knownErrors: Record<string, string> = {
      'DuplicateCheckin': 'errors.duplicate_checkin',
      'NotFound': 'errors.not_found',
      'Validation': 'errors.validation',
      'DataCorruption': 'errors.data_corruption',
      'BackupFailed': 'errors.backup_failed',
      'RestoreFailed': 'errors.restore_failed',
    };
    for (const [key, i18nKey] of Object.entries(knownErrors)) {
      if (error.includes(key)) return i18nKey;
    }
  }
  return 'errors.unknown';
}
```

### 2.5 关键组件实现要点

#### 2.5.1 ItemFormModal

- 表单字段与校验规则：
  - `name`：必填，trim后长度1-200，纯空格不允许
  - `purchasePrice`：正则 `/^\d+(\.\d{1,2})?$/`，范围0-99999999.99
  - `residualValue`：仅当 `isFixedAsset=true` 时显示，且必须 `< purchasePrice`
  - `usefulLifeYears`：整数1-100
  - `coolingDays`：整数1-365（愿望专用）
- 固定资产开关：`useState` 控制展开，切换关闭时若已填写折旧参数则弹出确认框询问是否保留
- 品类输入实现：使用组合框（Combobox），输入时过滤已有品类，无可匹配项时显示"创建 'xxx'"
- 提交：先调用前端校验，通过后调用 `addItem` 或 `updateItem`，成功后关闭弹窗并 toast 提示
- 编辑模式：所有字段预填已有值，`purchase_date` 从 ISO 字符串转为 `YYYY-MM-DD` 展示

#### 2.5.2 虚拟列表

使用 `@tanstack/react-virtual`，基于 `getItems` 返回的 `totalCount` 实现无限滚动：

```typescript
// components/business/ItemVirtualList.tsx
function ItemVirtualList() {
  const { items, totalCount, page, pageSize, fetchItems, setPage } = useItemStore();
  const parentRef = useRef<HTMLDivElement>(null);

  const virtualizer = useVirtualizer({
    count: totalCount,
    getScrollElement: () => parentRef.current,
    estimateSize: () => (viewMode === 'grid' ? 200 : 60),
    overscan: 5,
  });

  // 当virtualizer请求的数据不在缓存中时加载
  useEffect(() => {
    const range = virtualizer.range;
    const neededPage = Math.floor(range.end / pageSize) + 1;
    if (neededPage > page) {
      setPage(neededPage);
      fetchItems();
    }
  }, [virtualizer.range]);

  return (
    <div ref={parentRef} style={{ height: '100%', overflow: 'auto' }}>
      <div style={{ height: virtualizer.getTotalSize() }}>
        {/* 渲染可见项 */}
      </div>
    </div>
  );
}
```

```typescript
// hooks/useFormat.ts
export function useFormat() {
  const { i18n } = useTranslation();
  const localeMap: Record<string, string> = {
    'zh-CN': 'zh-CN',
    'zh-TW': 'zh-TW',
    'en': 'en-US',
  };
  const locale = localeMap[i18n.language] || 'en-US';

  const formatCurrency = (value: number | null | undefined, currency?: string) => {
    if (value == null) return '—';
    return new Intl.NumberFormat(locale, {
      style: 'currency',
      currency: currency || 'CNY',
      minimumFractionDigits: 2,
    }).format(value);
  };

  const formatDate = (date: string | Date | null | undefined, style: 'short' | 'long' = 'short') => {
    if (!date) return '—';
    const d = typeof date === 'string' ? new Date(date) : date;
    const options: Intl.DateTimeFormatOptions = style === 'long'
      ? { year: 'numeric', month: 'long', day: 'numeric' }
      : { year: 'numeric', month: '2-digit', day: '2-digit' };
    return new Intl.DateTimeFormat(locale, options).format(d);
  };

  return { formatCurrency, formatDate };
}
```

### 3.1 数据库模式 (DDL)

所有表存储在 `margarita.db`，启用 WAL 模式。


```rust
        let days_in_month = NaiveDate::from_ymd_opt(today.year(), today.month(), 1)

            .map(|next| (next - NaiveDate::from_ymd_opt(today.year(), today.month(), 1).unwrap()).num_days())

    let purchase_trend = repo.purchase_trend(12)?;
```

```rust
#[tauri::command]
pub async fn find_idle_match(
    repo: State<'_, InsightRepo>,
    engine: State<'_, IdleDetector>,
    price: f64,
) -> Result<Option<IdleMatchResult>, AppError> {
    let today = Local::now().date_naive();
    let threshold = 60; // 默认闲置阈值
    let candidates = repo.find_idle_candidates(false)?;

    let idle_items: Vec<IdleItemBrief> = candidates
        .into_iter()
        .filter_map(|item| {
            let last_checkin = repo.last_checkin_date(&item.id).ok().flatten();
            let days = engine.idle_days(last_checkin, today);
            if days >= threshold {
                Some(IdleItemBrief {
                    id: item.id,
                    name: item.name,
                    purchase_price: item.purchase_price,
                    accumulated_depreciation: item.accumulated_depreciation(),
                    current_net_value: item.current_net_value(today),
                })
            } else {
                None
            }
        })
        .collect();

    // 简单组合匹配：找1-3件总价与目标价格最接近的组合
    let target = price;
    let tolerance = price * 0.1;
    let mut best_match: Option<Vec<&IdleItemBrief>> = None;
    let mut best_diff = f64::MAX;

    // 1件匹配
    for item in &idle_items {
        let diff = (item.purchase_price - target).abs();
        if diff <= tolerance && diff < best_diff {
            best_match = Some(vec![item]);
            best_diff = diff;
        }
    }

    // 2件匹配
    for i in 0..idle_items.len() {
        for j in (i+1)..idle_items.len() {
            let sum = idle_items[i].purchase_price + idle_items[j].purchase_price;
            let diff = (sum - target).abs();
            if diff <= tolerance && diff < best_diff {
                best_match = Some(vec![&idle_items[i], &idle_items[j]]);
                best_diff = diff;
            }
        }
    }

    // 3件匹配
    if best_match.is_none() {
        for i in 0..idle_items.len() {
            for j in (i+1)..idle_items.len() {
                for k in (j+1)..idle_items.len() {
                    let sum = idle_items[i].purchase_price + idle_items[j].purchase_price + idle_items[k].purchase_price;
                    let diff = (sum - target).abs();
                    if diff <= tolerance && diff < best_diff {
                        best_match = Some(vec![&idle_items[i], &idle_items[j], &idle_items[k]]);
                        best_diff = diff;
                    }
                }
            }
        }
    }

    match best_match {
        Some(matched) => {
            let total_silent_cost: f64 = matched.iter().map(|i| i.purchase_price).sum();
            Ok(Some(IdleMatchResult {
                matched_items: matched.into_iter().cloned().collect(),
                total_silent_cost,
            }))
        }
        None => Ok(None),
    }
}
```

```rust
    // 复制备份文件覆盖当前数据库
    std::fs::copy(&src_db, &db_path)?;

    // 恢复图片目录
    let src_images = src.join("images");
    if src_images.exists() {
        if images_dir.exists() {
            std::fs::remove_dir_all(&images_dir)?;
        }
        copy_dir_recursive(&src_images, &images_dir)?;
    }

    Ok(())
}

fn copy_dir_recursive(src: &Path, dest: &Path) -> Result<(), AppError> {
    std::fs::create_dir_all(dest)?;
    for entry in std::fs::read_dir(src)? {
        let entry = entry?;
        let file_type = entry.file_type()?;
        let dest_path = dest.join(entry.file_name());
        if file_type.is_dir() {
            copy_dir_recursive(&entry.path(), &dest_path)?;
        } else {
            std::fs::copy(entry.path(), &dest_path)?;
        }
    }
    Ok(())
}
```

### 3.3 核心引擎算法详细设计

#### 3.3.1 折旧引擎 (`engine/depreciation.rs`)

```rust
use chrono::NaiveDate;

#[derive(Debug, Clone)]
pub struct DepreciationEngine;

#[derive(Debug)]
pub struct DepreciationInput {
    pub purchase_price: f64,
    pub purchase_date: NaiveDate,
    pub residual_value: f64,
    pub useful_life_years: u32,
    pub method: DepreciationMethod,
    pub calc_date: NaiveDate,
}

#[derive(Debug, Clone, Copy, PartialEq)]
pub enum DepreciationMethod {
    Linear,
    Accelerated,
}

#[derive(Debug)]
pub struct DepreciationResult {
    pub accumulated: f64,
    pub net_value: f64,
    pub daily_rate: f64,
    pub is_completed: bool,
}

impl DepreciationEngine {
    pub fn calculate(input: &DepreciationInput) -> DepreciationResult {
        let elapsed_days = (input.calc_date - input.purchase_date).num_days().max(0) as u32;
        let total_days = input.useful_life_years * 365;

        // 检查是否已进入维持期
        if elapsed_days >= total_days {
            let total_depreciable = input.purchase_price - input.residual_value;
            return DepreciationResult {
                accumulated: round_2(total_depreciable),
                net_value: round_2(input.residual_value),
                daily_rate: 0.0,
                is_completed: true,
            };
        }

        match input.method {
            DepreciationMethod::Linear => {
                let total_depreciable = input.purchase_price - input.residual_value;
                let daily = total_depreciable / total_days as f64;
                let accumulated = daily * elapsed_days as f64;

                DepreciationResult {
                    accumulated: round_2(accumulated),
                    net_value: round_2(input.purchase_price - accumulated),
                    daily_rate: round_2(daily),
                    is_completed: false,
                }
            }
            DepreciationMethod::Accelerated => {
                let rate = 2.0 / input.useful_life_years as f64;
                let years = input.useful_life_years;
                let elapsed_years = (elapsed_days as f64 / 365.0).floor() as u32;
                let switch_to_linear_at = if years >= 2 { years - 2 } else { 0 };

                let mut book_value = input.purchase_price;
                let mut accumulated = 0.0;

                for y in 0..elapsed_years {
                    if y < switch_to_linear_at {
                        // 双倍余额递减
                        let yearly_dep = book_value * rate;
                        let cap = book_value - input.residual_value;
                        let yearly_dep = yearly_dep.min(cap);
                        book_value -= yearly_dep;
                        accumulated += yearly_dep;
                    } else {
                        // 最后两年转为直线
                        let remaining = book_value - input.residual_value;
                        let remaining_years = years - y;
                        if remaining_years > 0 {
                            let yearly_dep = remaining / remaining_years as f64;
                            book_value -= yearly_dep;
                            accumulated += yearly_dep;
                        }
                    }
                }

                // 处理当年内已过的天数（简化：按天比例）
                let days_in_current_year = elapsed_days - elapsed_years * 365;
                if days_in_current_year > 0 && elapsed_years < years {
                    let yearly_dep = if elapsed_years < switch_to_linear_at {
                        (book_value + accumulated - input.purchase_price + accumulated).abs().min(book_value * rate)
                    } else {
                        let remaining = book_value - input.residual_value;
                        let remaining_years = years - elapsed_years;
                        if remaining_years > 0 { remaining / remaining_years as f64 } else { 0.0 }
                    };
                    let partial_dep = yearly_dep * (days_in_current_year as f64 / 365.0);
                    accumulated += partial_dep;
                    book_value -= partial_dep;
                }

                DepreciationResult {
                    accumulated: round_2(accumulated),
                    net_value: round_2(book_value.max(input.residual_value)),
                    daily_rate: round_2(accumulated / elapsed_days.max(1) as f64),
                    is_completed: false,
                }
            }
        }
    }
}

fn round_2(value: f64) -> f64 {
    (value * 100.0).round() / 100.0
}
```

```rust
use chrono::NaiveDate;

pub struct IdleDetector;

impl IdleDetector {
    pub fn idle_days(&self, last_checkin: Option<NaiveDate>, today: NaiveDate) -> u32 {
        match last_checkin {
            Some(date) => (today - date).num_days().max(0) as u32,
            None => u32::MAX, // 从未打卡视为长期闲置
        }
    }

    pub fn is_idle(&self, last_checkin: Option<NaiveDate>, today: NaiveDate, threshold: u32) -> bool {
        self.idle_days(last_checkin, today) >= threshold
    }

    pub fn calculate_idle_depreciation(
        &self,
        is_fixed_asset: bool,
        daily_rate: f64,
        idle_days: u32,
    ) -> Option<f64> {
        if is_fixed_asset && daily_rate > 0.0 {
            Some(round_2(daily_rate * idle_days as f64))
        } else {
            None
        }
    }
}

fn round_2(value: f64) -> f64 {
    (value * 100.0).round() / 100.0
}
```

#### 3.3.3 后悔指数 (`engine/regret_ranker.rs`)

```rust
use chrono::NaiveDate;

pub struct RegretRanker;

impl RegretRanker {
    pub fn regret_index(
        &self,
        rating: Option<u32>,
        idle_days: u32,
        net_value_rate: Option<f64>,
    ) -> f64 {
        let rating_factor = match rating {
            Some(r) if r >= 1 && r <= 5 => (5 - r) as f64 / 4.0,
            None => 0.5,
            _ => 0.5,
        };

        let idle_factor = (idle_days.min(365) as f64) / 365.0;

        let net_factor = net_value_rate
            .map(|nv| {
                let clamped = nv.clamp(0.0, 1.0);
                1.0 - clamped
            })
            .unwrap_or(0.5);

        let index = rating_factor * 0.3 + idle_factor * 0.4 + net_factor * 0.3;
        (index * 100.0).round() / 100.0
    }

    pub fn net_value_rate(
        &self,
        purchase_price: f64,
        current_net_value: Option<f64>,
    ) -> Option<f64> {
        if purchase_price > 0.0 {
            current_net_value.map(|nv| (nv / purchase_price).clamp(0.0, 1.0))
        } else {
            None
        }
    }
}

#[cfg(test)]
mod tests {
    use super::*;

    #[test]
    fn test_high_regret() {
        let ranker = RegretRanker;
        // 评分1星，闲置365天，净值只剩10%
        let index = ranker.regret_index(Some(1), 365, Some(0.1));
        assert!(index > 0.8); // 高后悔
    }

    #[test]
    fn test_low_regret() {
        let ranker = RegretRanker;
        // 评分5星，闲置0天，净值100%
        let index = ranker.regret_index(Some(5), 0, Some(1.0));
        assert!(index < 0.2); // 低后悔
    }

    #[test]
    fn test_unrated() {
        let ranker = RegretRanker;
        let index = ranker.regret_index(None, 180, Some(0.5));
        assert!(index > 0.3 && index < 0.7);
    }
```

## 4. 关键流程与状态机

### 4.1 物品生命周期状态机

```
  +--------+
  | ACTIVE |  ←── (新建时默认)
  +--------+
    |
    | 退役操作
    v
  +---------+
  | RETIRED |   (不再参与折旧、闲置、仪表盘)
  +---------+
    |
    | 恢复操作
    v
  ACTIVE
```

固定资产额外有折旧阶段：

```
ACTIVE (折旧中) → 使用年限到达 → ACTIVE (维持期，is_completed=true)
```

维持期仅影响折旧计算，状态仍为 ACTIVE。

### 4.2 愿望冷却状态机

```
COOLING (冷却中) → 冷却天数完毕 → REVIEWABLE (待评估)
    |
    | 不允许提前结束冷却
    |
REVIEWABLE  → 用户点击"确认购买" → status = PURCHASED
            → 用户点击"放弃" → status = ABANDONED，写入克制记录
```

**状态变更规则**：
- COOLING → REVIEWABLE：由系统在查询时自动判断（`created_at + cooling_days <= today`），不需定时任务
- REVIEWABLE → PURCHASED/ABANDONED：用户操作触发
- 不允许从 COOLING 直接跳转到 PURCHASED/ABANDONED

### 4.3 数据初始化流程

应用首次启动：

1. 主进程初始化 SQLite 连接，执行 migrations 创建表。
2. 检查 `categories` 表是否为空，为空则插入预设品类：

## 5. 前后端通信与状态同步

- 所有数据变更通过 `invoke` 异步返回结果后，前端调用对应 store 的更新方法。
- 仪表盘数据在以下时机自动刷新：
  - 应用启动
  - 物品增删改后

- 前端组件间通信通过 Zustand store 共享状态，不直接跨组件传参。

  - 单个组件超过 300 行考虑拆分为子组件
- **类型安全**：禁止使用 `any`，确有必要时使用 `unknown` 并加类型守卫
- **导入顺序**：第三方库 → 项目内绝对路径模块 → 相对路径模块，各组间空行分隔

#### 7.3.2 后端 (Rust)

- **格式化**：使用 `rustfmt`，默认配置
- **Lint**：使用 `clippy`，CI 中开启 `-D warnings`
- **模块组织**：
  - `mod.rs` 仅声明子模块和重导出
  - 每个命令函数不超过 50 行，复杂逻辑下沉到 engine/services
- **错误处理**：
  - 所有可恢复错误使用 `Result<T, AppError>`
  - 禁止在库代码中使用 `unwrap()` 和 `expect()`，仅测试代码例外
  - 使用 `?` 传播错误，在命令层转换为用户友好信息
- **数据库操作**：
  - SQL 语句定义在 `db/` 层
  - `commands/` 层不得直接拼接 SQL

### 7.4 注释规范

| 场景 | 规范 | 示例 |
| :--- | :--- | :--- |
| 公共API函数 (前端) | JSDoc 描述参数与返回值 | `/** @param itemId - UUID of the item @returns The deleted item */` |
| 公共函数 (Rust) | `///` 文档注释，描述功能、参数、返回值和可能错误 | `/// Calculates depreciation based on method and elapsed days.` |
| 复杂算法 | 行内注释解释步骤，注明公式来源 | `// Linear: daily = (cost - residual) / total_days` |
| 业务规则 | 注释标注对应的 PRD/PDD 条款号 | `// PRD 5.6.4: 折旧完成进入维持期` |
| TODO/FIXME | 统一格式 `// TODO(角色): 描述`，提 PR 前应清理 | `// TODO(v2.0): 实现加速折旧按日迭代精确计算` |

### 7.5 Git 提交规范

采用 Conventional Commits 规范：

```
<type>(<scope>): <subject>

[body]
```

**type 枚举**：

| type | 说明 |
| :--- | :--- |
| `feat` | 新功能 |
| `fix` | Bug修复 |
| `refactor` | 重构（非功能变更） |
| `style` | 格式调整（不影响逻辑） |
| `docs` | 文档变更 |
| `test` | 测试相关 |
| `chore` | 构建/工具/依赖变更 |

**scope 枚举**：`item`, `dashboard`, `insight`, `decision`, `settings`, `engine`, `db`, `i18n`

**示例**：

```
feat(item): 添加固定资产折旧开关与字段展开

- 实现前端ItemFormModal中is_fixed_asset开关
- 添加residual_value、useful_life_years条件必填校验
- 后端add_item/update_item命令同步支持折旧参数
```

**分支策略**：

```
main          # 稳定发布分支
  └── dev     # 开发集成分支
        ├── feat/item-form   # 功能分支
        ├── fix/idle-calc    # 修复分支
        └── chore/update-deps
```

### 7.6 错误处理规范

#### 7.6.1 前端

- 所有 `invoke` 调用必须被 `try/catch` 包裹
- 错误类型分为三类处理：

| 错误类型 | 处理方式 |
| :--- | :--- |
| 用户输入错误（校验失败） | 表单字段下方显示红色提示，不弹窗 |
| 业务逻辑错误（如重复打卡） | Toast 提示，2秒自动消失 |
| 系统错误（数据库损坏、IO失败） | 错误边界或模态框提示，引导用户备份恢复 |

- 错误文案统一从语言文件读取，不硬编码

#### 7.6.2 后端

- 命令层统一返回 `Result<T, AppError>`
- 数据库层错误通过 `?` 向上传播，使用 `map_err` 转换为业务错误
- 关键操作（写数据库、文件I/O）错误需记录到应用日志，不包含用户隐私数据

### 7.7 日志规范

- 使用 `log` crate（Rust端）和 `console`（前端，仅开发模式）
- 日志级别使用：

| 级别 | 场景 |
| :--- | :--- |
| `error` | 数据库损坏、文件写入失败、恢复失败 |
| `warn` | 折旧参数异常、闲置阈值超出常规范围、缩略图生成失败 |
| `info` | 应用启动、数据库迁移完成、备份成功 |
| `debug` | SQL执行、命令调用、折旧计算详情（仅开发环境） |

- **隐私保护**：日志中不得记录物品名称、价格、路径等用户数据，仅记录 ID 或计数

### 7.8 性能规范

- 前端列表超过 50 项即启用虚拟滚动（`@tanstack/react-virtual`）
- 数据库查询必须使用索引覆盖，避免全表扫描
- 图片在列表中使用缩略图，详情页按需加载原图
- React 组件使用 `React.memo` 和 `useMemo`/`useCallback` 避免不必要的重渲染
- 仪表盘数据缓存：除非物品变更触发刷新，否则复用上次结果
- 数据库连接使用单例，WAL 模式，避免频繁开关

### 7.9 国际化开发规范

- 新增任何面向用户的文案，必须在三个语言文件中同步添加，key 使用嵌套命名空间（如 `inventory.form.nameRequired`）
- 不允许在代码中硬编码用户可见的文本，包括按钮、提示、错误信息
- 后端错误码以常量或枚举定义在 `utils/error.rs`，前端语言文件中维护映射
- 日期和货币显示统一使用 `useFormat` hook，不手动拼接格式字符串

### 7.10 测试规范

| 类型 | 覆盖范围 | 工具 | 要求 |
| :--- | :--- | :--- | :--- |
| 单元测试 (Rust engine) | 折旧、闲置、后悔榜算法 | `cargo test` | 每个函数至少 3 个用例，覆盖边界值 |
| 单元测试 (Rust db) | 数据库 CRUD 操作 | `cargo test` + 内存 SQLite | 覆盖增删改查和约束冲突 |
| 单元测试 (前端) | 表单校验、工具函数 | Vitest | 临界值和异常输入 |
| 集成测试 (Rust) | Tauri 命令端到端 | `cargo test` | 覆盖主要命令 |
| E2E (可选) | 完整用户流程 | Playwright | 核心流程一条 Happy Path |
